## 🚀 Featured Projects

**[LightningParse](https://github.com/ShivamMalge/LightningParse)** — Rust + PyO3 PDF parsing library for RAG pipelines, shipped to PyPI (v0.3.0). Built through a seven-phase pipeline with verification gates at every phase.

**Verity** — RAG-based audiobook/literary analysis platform using LangGraph orchestration, Qdrant Cloud, and Gemini APIs, with a multi-tenant admin/user architecture on FastAPI.

**Personal Finance Tracker** — Full-stack app (Next.js, Express, PostgreSQL, Prisma, Docker), including a cross-site cookie fix via a Vercel rewrite proxy.

**700-Question DSA Tracker** — Excel-based tracker spanning all 14 target companies, with a live dashboard, pattern-complexity tracking, and formula-linked summary sheets.
